# PERMANENT SEO CONTENT OPERATING SYSTEM

This document defines the permanent rules, quality gates, and workflow engines for all SEO content on Teleview.

## Core Principle
**USER VALUE → SEARCH INTENT → ORIGINAL VALUE → ACCURACY → EXPERIENCE → CLARITY → SEO**

SEO is the final optimization layer, not the reason the content exists.

---

## THE THREE-PROMPT SYSTEM

Every SEO content task must proceed through three non-negotiable phases in strict order:

### Phase 1: Research / SEO Brief
Before writing:
1. Understand the target keyword.
2. Determine the real search intent (Commercial, Informational, Navigational, Comparative).
3. Identify the user's practical problem or goal.
4. Analyze SERP patterns when data is available.
5. Identify required entities and topical coverage.
6. Identify user questions that must be addressed.
7. Identify competitor coverage and competitor weaknesses.
8. Identify content gaps.
9. Determine original value the site can realistically provide.
10. Determine first-hand evidence available (never fabricated).
11. Determine logical internal links with natural anchors.
12. Determine which technical/commercial claims require verification.

**The brief must contain:**
* Primary keyword
* Search intent
* Secondary intents
* Target audience
* Required entities
* User questions
* SERP patterns
* Competitor weaknesses
* Content gaps
* Unique angle
* Original value opportunities
* First-hand evidence opportunities
* Internal linking opportunities
* Sources requiring verification
* Recommended structure

*Do not begin writing until the brief is logically complete.*

---

### Phase 2: Copywriting
Write strictly from the approved research brief.
* Answer the main question immediately above the fold.
* Keep language clear, concrete, and concise.
* Use descriptive, hierarchical headings (H1, H2, H3).
* Use bullets and tables only when they measurably enhance comprehension.
* Explain technical networking/IPTV concepts accurately.
* Provide step-by-step practical troubleshooting where relevant.
* Eliminate filler, fluff, and unnecessary repetition.
* Never write to a predetermined word count.
* No automatic "Introduction" or "Conclusion" boilerplate.
* No automatic FAQ sections unless addressing genuine, unaddressed user inquiries.

---

### Phase 3: SEO Quality Engine (Adversarial Gate)
Before publication, evaluate the content with the explicit objective of finding flaws to reject it.

**Evaluation Dimensions:**
1. **Search Intent**: Does the content solve the user's problem within seconds?
2. **Original Value**: What does this page provide that generic AI answers cannot?
3. **First-Hand Evidence**: Are claims grounded in verifiable facts? (Zero fabricated benchmarks/reviews).
4. **Accuracy**: Are device OS versions, protocols (M3U, Xtream Codes), and networking facts verified?
5. **AI Boilerplate**: Are banned generic phrases completely absent?
6. **Template / Scaled Risk**: Does the page feel unique rather than programmatically generated?
7. **Topical Depth**: Are all user expectations answered without bloat?
8. **Keyword Integration**: Are keywords integrated naturally without density manipulation?
9. **Internal Linking**: Do all links point to logical destinations with natural user benefit?
10. **Commercial Claims**: Are uptime, buffering, refund terms, and channel listings strictly factual?

**Automatic Rejection Triggers:**
* Search intent unsatisfied or blurred.
* Fabricated experience, benchmarks, reviews, or testing.
* Unsupported superlatives ("100% uptime", "zero buffering", "guaranteed compatibility").
* Substantially generic or templated text.
* Sections created solely for keyword stuffing.
* Factual errors in IPTV specs (codecs, player setup, device constraints).
* Misleading commercial statements.

*When any criterion fails, return FAIL with specific required fixes. Never publish until all checks PASS.*

---

## BANNED AI BOILERPLATE PHRASES
Never use the following generic clichés:
* "In today's digital landscape"
* "Whether you're a..."
* "Unlock the power of..."
* "Leverage..."
* "Seamlessly..."
* "Game-changing"
* "Ultimate guide"
* "Revolutionize"
* "Everything you need to know"

Prefer direct, factual explanations.
